# ZELICLOUD

**让垂直行业数字化更快落地**

聚焦物业管理（PropFlow）、医疗服务（Medical）与赛事运营（Martial）三大场景，提供从后端到多端应用的一体化研发与交付。

## 产品方向

### PropFlow · 物业管理系统

- 物业管理端 App
- 用户端 App
- 配套工具链与项目文档

### Medical · 医疗业务系统

- 医疗业务后端
- 管理端 Web
- 小程序端

- 赛事后端
