## 关于 ZELICLOUD

我们从业务现场出发，把角色、流程、数据和交付约束落到系统里。研发覆盖后端服务、管理端 Web、移动端与配套文档，让垂直行业的数字化建设更容易开始，也更容易持续迭代。

## 产品方向

### PropFlow · 物业管理

围绕物业业务协同，把管理后台、移动端服务和项目文档连接成一套可持续交付的产品能力。

- 物业业务管理后台
- 管理端 App 与用户端 App
- 配套工具链与项目文档

### Medical · 医疗服务

围绕医疗业务流程，连接后端服务、管理端 Web、小程序和智能设备协同场景。

- 医疗业务后端
- 管理端 Web
- 小程序与智能设备联动端

### Martial · 赛事运营

围绕武术赛事的组织与执行，让报名、编排、执裁和结果沉淀在同一条业务链路上。

- 赛事后端
- Web 管理端
- 用户报名端与裁判执裁端

## 工程能力

当前常用技术栈：

`Java` `Vue` `TypeScript` `Python`

我们重视清晰的业务边界、可复用的模块和持续完善的项目文档，让产品从一次性交付走向长期演进。
